# Prototype 01: structured knowledge fast path
Import five-column TSV claims with mandatory source and category labels. Deduplicate normalised triples, retain multiple sources and overlapping categories, query subject/relation or category with bounded result counts. Snapshot is deterministic for a given insertion history. CLI creates a new file only; no overwrite. All claims remain unverified. Conflicting/multi-valued answers are returned, not resolved. This is a deterministic lookup baseline inspired by ALICE, not a semantic Graphmaster, SLM or AI curation engine. Next: disk-backed indexed records and memory budgets; evidence model and temporal scope; semantic extraction and router; compare against SQLite and existing engines before choosing storage.
