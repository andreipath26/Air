# Prototype 08 — typed dataflow and resident runtime
The dataflow executor composes reviewed single-value lookups, checked integer arithmetic and explicitly approved skill versions; references are to earlier typed outputs only. It stops on unresolved lookup or approval, with sixteen-node maximum. The resident JSON-lines API retains opened stores across requests and exposes read-only inference/plan/dataflow over stdio, not TCP. Invalid requests return a structured error; oversized requests terminate the stream. Predictive memory learns bounded empirical transition counts; a RAM-node weightless classifier learns discrete token-bit patterns, with ties abstaining. These are library-level experiments, not yet active routing backends or calibrated probabilities. No general autonomous planning, neural-to-symbolic compiler, validated quality improvement or deployment readiness claim.
