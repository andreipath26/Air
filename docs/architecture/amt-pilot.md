# AMT pilot 01
This is a runnable first behavioural conversion experiment, not a converted foundation model. A trusted local llama.cpp-compatible teacher returns integer demonstrations for an explicit task description. Independently supplied reference answers filter discovery and validation traces; a separate final split evaluates teacher and compiled candidate. Only a restricted binary expression grammar is searched. The mock teacher test is a protocol and synthesis regression, not real-model evidence. The pilot pass criterion is exact compiled correctness on every final case and nonzero teacher correctness; it is intentionally a small capability test, not the roadmap acceptance gate. The final test is public and not a statistically representative blind benchmark. Spec author must supply independently generated references and exact teacher identity/license; the server binding is operator-attested, not cryptographically verified. The report records client-side conversion and test latencies, not total RAM or energy. Candidate import is explicitly unapproved; use existing review/approval controls. SafeTensors inspection supports common scalar dtypes, validates extents and computes streaming SHA-256, without interpreting weights or running pickle. No GGUF inspector, activation analysis, automatic factual transfer, model removal, full lifecycle benchmark or hardware validation yet.
