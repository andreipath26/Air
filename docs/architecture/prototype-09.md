# Prototype 09 — learned category fallback and reversible knowledge
The persistent operator-trained RAM-node classifier supplies category suggestions after ordinary routing and optional local-model routing abstain. It never marks a category result as a resolved answer. Current implementation retrains from at most 4096 stored examples on each fallback; it is not a resident optimised classifier, and lexical collisions can cause irrelevant suggestions. Predictive transition memory is accessible through observe/predict CLI commands but does not yet drive prefetch. Versioned content-addressed objects preserve previous revisions and append rollback events; this is a separate knowledge object store, not transactional rollback of the active indexed fact store. Rejected claims are also excluded from two-hop evidence paths. Diagnostic counter types are groundwork, not connected telemetry. No phase gates or scientific targets established.
