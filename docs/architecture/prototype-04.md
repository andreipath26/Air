# Prototype 04 — cognitive and compiled execution experiments
Semantic memory remains Indexed. Episodic memory persists explicit cue/outcome records, with lexical binary association over a bounded recent window; not autonomous memory or semantic embeddings. Procedural memory stores versioned restricted integer expression programs. Working memory bounds payload and item count. Candidate induction enumerates four operations from distinct demonstrations; ambiguous/unmatched traces abstain. A unique fit is not a proof of intended behaviour. Compiler emits stack instructions and folds constant expressions only when checked arithmetic succeeds. No arbitrary code, recursion or host access. Run on unseen inputs; older versions remain inspectable through the library API. Binary hashed token signatures are a non-neural lexical baseline, not a trained weightless network or proof of intelligence. Deterministic multilingual templates handle capital relations and status messages; other relations retain original language. Evidence assessment distinguishes missing, incomplete, single unverified and multiple values without asserting contradiction or independent verification. The prototype has no independent claim truth verifier, advanced causal/probabilistic engine, general neural behaviour extraction, learned semantic deduplication, automatic skill publication approval, whole-system memory guarantee or measured quality/energy advantage. All phase gates remain open.
