# G01 corpus and measurement pipeline

The corpus builder accepts a separate reviewed knowledge corpus, never the final question workload. It creates reference-fed and teacher-fed stores independently. Teacher responses are recorded and only exact normalized reference matches are admitted. Supplied reviewer declarations are not authenticated; do not confuse reference matching with independent review. A failed or empty conversion retains its trace. The teacher identity is declared by the operator; the existing benchmark validates the actual baseline binary and GGUF file hashes.

The benchmark now samples Linux system used memory and optional Intel RAPL CPU package energy as diagnostics, in addition to process RSS. Memory includes background activity; package energy excludes other system components and is never substituted for whole-system energy. The assembler requires separately supplied instrument/method information, declared whole-system measurement scopes, exact observation hashes, identical workload IDs and matching AIR binary/router identities. It rejects failed requests rather than counting them as correct abstentions. Measurements remain subject to independent review.

The corpus smoke fixture is not independent gate evidence. Final corpus and test authoring, source/license audit, frozen workload and quantized teacher pins, external power measurement, warm/cold repeat protocol and Dell execution remain outstanding. The batch review CLI is explicit operator import and not a transactional multi-database publication mechanism. Incomplete output directories must not be reused as validated packages.
