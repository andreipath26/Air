# Consolidated G01 work

Shared answer extraction distinguishes malformed, explicit abstention, incorrect and reference-matched responses. Scientific and SI symbols preserve case; Unicode micro-sign aliases are normalized. Accepted facts use the reviewed reference spelling. This does not fix the generic indexed store's case-folded object uniqueness; G01 admits one reference answer per subject/relation, and generic case-sensitive multi-valued facts remain a limitation. The lexical fallback uses exact entity spans and exact content-word signatures, not an embedding or general semantic parser. Negation and compound questions fail closed. Equal-L2 disjoint perturbations improve control strength but are not individually magnitude-matched zero ablations. The quantized development workflow requires explicit verified llama.cpp and GGUF revisions and hash; it has not been run yet. The review tool records externally supplied assertions and refuses draft fixture references, rather than claiming independent review.

Historical 0.5B development artifact from AMT run 45978770516 (teacher revision `7ae557604adf67be50417f59c2c2f167def9a775`): teacher-fed AIR answered 152/240 (63.3%), the FP32 teacher 121/240 (50.4%), and reference-fed retrieval 240/240 (100%). One teacher answer was malformed; all 502 requests logged by that job received HTTP 200. The earlier script mislabeled the malformed output as a transport failure and consequently failed the pilot job.

Corrected 0.5B result from AMT run 45982358534, artifact 15189469633, teacher revision `7ae557604adf67be50417f59c2c2f167def9a775`: teacher-fed AIR 157/240 (65.4%), FP32 teacher 121/240 (50.4%), and reference-fed retrieval 240/240 (100%). The teacher job reported one malformed answer, nine abstentions and zero transport errors, and passed.

The completed 1.5B job from the same run, artifact 15190766881, teacher revision `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`, accepted 190/200 draft facts and scored teacher-fed AIR 230/240 (95.8%) versus 186/240 (77.5%) for the FP32 teacher. Reconciliation artifact 15191510844 built a reference-validated 192/200-fact union; AIR scored 232/240 (96.7%), with 96% geography, 100% science, 98% engineering, 90% general reference, and 100% unknown abstention. The 100% direct-reference result is an oracle-style ceiling. Both the corpus/questions and paraphrases are same-author development data, unsupported cases are synthetic, and the teacher remained resident during AIR timing. The two teachers also belong to the same model family. These are strong development diagnostics, not G01 evidence. The target-machine whole-system measurements and independent review remain open.

The 0.5B trace shows a knowledge-coverage bottleneck in engineering and general-reference questions: the router resolves the queried subject/relation, but most corresponding facts were not accepted into the teacher-fed store. A stricter relation-aware parser now handles a few verbose symbol answers (for example, `Watts (W)` and `Coulomb is represented by the symbol C.`) while still requiring an exact match to the reference answer before accepting a fact. Offline replay of the saved 0.5B conversion trace recovers four more engineering candidates, moving accepted draft facts from 117/200 to 121/200. This replay does not rerun AIR or establish a new end-to-end accuracy score; the post-fix benchmark is still needed.
