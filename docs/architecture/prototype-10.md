# Prototype 10 — capability packages and execution safety
Skill approvals now bind exact serialized program content plus name/version, and execution uses the same loaded program that was checked. Legacy approvals fail closed and must be renewed. Explicit revocation is supported. Conflicting or multi-result knowledge is conservatively incomplete. Portable AMT procedure packages include report and program SHA-256, teacher identity and bounded pilot metadata; explicit experimental execution is not integrated-session approval. Hashes are not signatures, and untrusted reports can forge evaluation claims. Resident JSON-line metrics expose request/error counts and top-level ask model calls/completions; nested plan/dataflow model calls are not counted and no whole-system resource guarantee is made. No acceptance gates passed.
