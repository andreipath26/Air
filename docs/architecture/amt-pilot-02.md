# AMT pilot 02
Three transfer tracks: integer procedure synthesis, factual extraction checked against explicit reference fixtures, and weightless classification trained on teacher outputs agreeing with labelled examples. Factual retrieval uses canonical keys, not autonomous paraphrase interpretation or unseen fact generalisation. Facts remain unapproved. Public fixtures are small and not independently audited. Streaming F32/BF16/F16 statistics expose numerical distributions, not decoded concepts. The real-model workflow resolves a model revision, records hashes, checks the declared Apache-2.0 license, loads SafeTensors with remote code disabled and runs CPU-only Qwen through a loopback bridge. It uploads results, including negative results. Rerun with --revision SHA for reproducibility. No whole-system energy or simultaneous-process memory measurement, model pruning or direct semantic weight inversion. The Python bridge is research-only.
