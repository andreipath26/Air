# Integrated prototype 05
The session command connects deterministic routing, operator aliases, local-model fallback on missing retrieval, indexed facts, episodic memory, versioned procedures, language rendering and review metadata. Explicit skill invocation requires approval of its exact current version; standalone legacy run-skill remains a manual experimental command. Operator reviews are revisioned, not independent truth guarantees; review database is trusted local state, separate from model ingestion. Alias mappings are one-hop, manually supplied and query-side only, not automatic semantic merging. No autonomous approval. A two-premise rule executor requires operator-accepted premises and explicitly supplied rule; output preserves premises and is conditional on rule validity. No arbitrary code or unbounded recursion. Expanded synthesis enumerates small expressions with separate validation inputs; it chooses a shortest fitting candidate, not a uniquely proven behaviour. Validation examples influence candidate selection and are not an independent final test. No general synthesis, probabilistic calibration, causal identification, learned semantic deduplication or full AI benchmark. Session completeness is an execution/approval indicator, not a guarantee of truth. The standalone legacy commands are retained. Actual local model/hardware validation and source audits remain pending.
