# Prototype 11 — portable classifier candidates and representation comparison

The AMT classification report now compares the weightless classifier, a conventional multinomial naive Bayes classifier using exactly the accepted teacher demonstrations, and the same lexical baseline trained on all reference training labels. The last baseline is deliberately not teacher transfer: it measures whether teacher involvement adds value. All classifiers use disjoint test inputs. This is still small public-fixture evidence, not an independent benchmark.

Classifier packages preserve training examples, teacher identity, report digest, training digest and pilot metrics. Experimental offline execution is separate from explicit operator installation. Installation into routing is atomic and rejects packages with fewer than 20 test cases, below 80% absolute accuracy, above 10% abstention, or fewer than two accepted demonstrations per category. These are preliminary eligibility checks, not independent validation or proof that a report is authentic. Package digests detect corruption, not fraud. Category suggestions are incomplete answers, never facts. Explicit classify requests bypass the model. Model routing errors fall back to suggestions/abstention; no invented answer.

Representation selection accepts only explicit measured validation candidates above quality, coverage and storage thresholds, then sorts by time per correct response and size. The caller must supply a validation split separate from final test. No automatic selection from final test data. Arithmetic reports now retain per-example teacher and compiled answers, allowing independent analysis. Real-model workflows emit portable candidate artifacts when available; previous small classification fixtures cannot be installed under the new threshold.

General language understanding, direct semantic weight extraction, neural residual integration, independent dataset validation and whole-system resource measurements remain open.
