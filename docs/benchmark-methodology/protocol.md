# Benchmark protocol

Use identical task distributions and hardware, frozen independent train/dev/test splits and contamination checks. Record exact model hashes, quantisation, context, thread counts, OS, power settings, warm/cold cache, dataset version and seeds. Compare quality per category, cross-domain and unseen compositions. Measure median and p95 end-to-end latency, first response, throughput, peak RSS/PSS, disk bytes, storage footprint, CPU cycles/instructions/cache misses, energy via calibrated RAPL or external meter where available; report unavailable counters as null rather than zero. Include router, retrieval, indexes, caches, verifier and output generation. Report teacher/curation/compiler cost separately and amortisation across task volume. Repeat runs, report variation and negative results. Baselines B01–B12 in research ledger. Initial gates are research targets only. The current air-bench binary measures a synthetic loop solely to exercise timing/JSON output, not intelligence or energy.
